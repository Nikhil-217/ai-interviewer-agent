# Antigravity AI Interview Agent Skills

Project-specific Antigravity skills for the AI Interview Agent hackathon.

## Included
1. interview-agent
2. curriculum-rag
3. interview-evaluator
4. agent-testing
5. api-deployment

## Installation
Copy the `skills` folders into your Antigravity workspace skill directory according to your installed Antigravity configuration.

Each skill contains a `SKILL.md` with YAML frontmatter and project-specific instructions.

## Recommended architecture
Candidate Profile -> Curriculum Retrieval -> Interview Agent -> Answer Evaluator -> Adaptive Follow-up -> Structured Feedback

## Important
Use the hackathon's Technical Specification as the source of truth for the required HTTP API contract.
